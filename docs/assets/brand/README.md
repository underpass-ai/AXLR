All exports have transparent backgrounds and the same four diagonal Spectrum bars, in red `#f04445`, yellow `#ffda36`, green `#32cd76` and cyan `#42d4ed`. Keep the bars with the complete wordmark and preserve each image's aspect ratio.

The KMP SVG retains the current KMP wordmark's colored pixel shapes. The MADE SVG retains MADE's distinct pixel lettering and omits the background, tagline and “by Underpass” line. The AXLR PNG retains the supplied [original raster lettering](../axlr-wordmark.png); no vector master for AXLR is available in this repository. Each PNG is an export for direct use; the SVGs remain the editable sources for KMP and MADE.
