All exports have transparent backgrounds and the same four diagonal Spectrum bars, in red `#f04445`, yellow `#ffda36`, green `#32cd76` and cyan `#42d4ed`. Keep the bars with the complete wordmark and preserve each image's aspect ratio.

All six files are generated by the dependency-free [pixel wordmark renderer](../../../tools/pixelart/README.md). Edit its terminal-art definitions to change lettering, color or layout, then regenerate both formats from the same source. CI verifies the committed exports.

KMP retains its current colored pixel shapes. MADE retains its distinct pixel lettering and omits the background, tagline and “by Underpass” line. AXLR's supplied [original raster](../axlr-wordmark.png) remains as a reference; its letters and stepped outlines are now reconstructed as vector shapes. Every SVG contains only rectangles and polygons, with no fonts or embedded bitmap.
